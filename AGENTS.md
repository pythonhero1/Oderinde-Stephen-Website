# Website design instructions

Before editing page design or creating reusable UI, read `docs/design-library/README.md` and inspect the matching original screenshot in its `references/` directory. These owner-supplied templates are the approved visual references. Use their composition and original artwork faithfully, with the measured live homepage gradients and colours recorded in that library.

Preserve all existing page content, images, links, sections and their order unless the owner explicitly requests a content change. Styling and responsiveness requests do not authorize removing, hiding, replacing or rewriting those items. Adapt layouts to mobile without dropping content. Keep changes on the Cloudflare preview for review; do not change the main domain without the owner's instruction.
